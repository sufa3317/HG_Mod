## ✨ 功能概览（v3.0 · code 300）

| 功能 | 说明 |
|---|---|
| 🚫 **去除视频流广告** | 拦截短剧贴片广告、电商卡片、购物 Feed、一站式广告等 |
| 👑 **解除 VIP / 付费限制** | 本地解锁 VIP 与付费判断（服务端校验仍可能受限） |
| ⏩ **播放倍速增强** | 面板补 1.75x / 锁定倍速 / 记忆倍速（重启自动恢复上次设定） |
| 🎞️ **强制指定画质** | 锁定 1080P 等档位，手动切低、切集后自动拉回 |
| 💎 **隐藏控件** | 福袋/商城/赚钱 Tab + 控件隐藏 + 实时悬浮规则修改 |
| 🌟 **双击清屏** | 双击只留视频，可自定义清屏保留控件 |
| 📺 **自动隐藏状态栏** | 播放页隐藏状态栏 + 拦截顶缘下拉防误切视频 |
| 🛡 **禁用热更新** | 挡住红果的热修补丁（Reparo），防止运行时改宿主类 |

## 🖥️ 动态适配
- **自动扫描红果内部结构**并缓存，宿主升级自动重扫；
- 混淆类（单字母）**结构特征匹配**动态定位，不依赖写死类名，**版本更新不易失效**;
- 扫描失败自动兜底到已知名，绝大多数功能有运行时兜底。

## 📦 安装

1. 设备需 **Root** 并安装 **LSPosed / Zygisk Next / 内核级框架**（支持 libxposed API 102）。
2. 安装本模块 APK，在框架里**启用模块**，作用域勾选【红果免费短剧】。
3. **强行停止红果 → 重新打开**，进短剧播放页同意协议、等待适配完成即可。

## ⚙️ 设置入口
- **红果内**：「我的 → 设置 → 白果助手」
- **桌面**：桌面图标 / LSPosed 模块入口
- 两入口读同一份配置文件，设置同步。

## 🛠️ 构建
需要 Android SDK（javac + d8 + aapt2 + apksigner），运行 `build.sh`（assembleDebug 或直接跑脚本）。

```
git clone <repo-url>
cd <repo>
./build.sh        # 或按你的构建流程
```

- 产物：`app-debug.apk`（或 release APK）
- 版本：`versionName=3.0`，`versionCode` 单调递增（当前 300）。
