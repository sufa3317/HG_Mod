# 白果助手（红果免费短剧 · Xposed 增强模块）

一个基于 **LSPosed / libxposed（API 102）** 的红果免费短剧（`com.phoenix.read`）功能增强 Xposed 模块，覆盖去广告、解锁 VIP、倍速、画质、界面精简与观看体验优化。

---

### 1) 🚫 去除视频流广告
- 拦截**短剧贴片广告**（配置层 + 展示层双层策略，日志可分辨是哪层拦下）
- 拦截**电商卡片 / 购物 Feed / 一站式短剧广告**
- 拦截播放页里的**卡片页广告、信息流广告位**等非标准广告

### 2) 👑 解除 VIP / 付费限制
- 本地解锁 VIP 与付费判断（`NsVipImpl`）
- ⚠️ 仅本地层面解锁，服务端校验仍可能受限

### 3) 🏎️ 播放倍速增强（三合一）
- **补 1.75x 档位**：同时补进标题栏、更多面板、智能面板等所有倍速来源
- **锁定播放倍数**：把倍速锁死在指定值（0.75 ~ 3.0）
- **记忆播放倍数**：记住你上次设的倍速，**重启应用自动恢复**，不丢配置
- 记忆 / 锁定（二选一）

### 4) 🎞️ 强制指定画质 
- 档位：1080P（最高）/ 720P / 540P / 480P / 360P / 自动

### 5) 💎 隐藏控件（控件设置）
- **总开关** + 逐项勾选（福袋挂件 / 商城 / 赚钱 Tab）
- **控件隐藏 / 清屏保留**两套独立规则
- **实时悬浮规则修改**：可拖动悬浮窗点哪选哪，精确记住单个控件
- **自定义隐藏 / 保留规则管理**：删除已保存规则
- 关总开关 1 秒内自动恢复已隐藏控件，不重启

### 6) 🌟 双击清屏
- 播放页双击只留视频，再双击恢复（单击仍是暂停）
- **清屏保留控件**：弹幕 / 播放暂停按钮 / 长按倍速提示 逐个可选保留
- 可自定义「清屏保留/隐藏」细粒度规则

### 7) 📺 自动隐藏状态栏
- 仅在**短剧播放页**隐藏状态栏，离开即恢复
- 隐藏后**拦截顶缘下拉手势**，防止下拉状态栏时误切到上一个视频

### 8) 🛡 禁用热更新（Reparo）
- 挡住红果的热修补丁（字节 Reparo），防止运行时改宿主类

### 9) ⚙️ 其它增强
- **显示缩放（DPI）**：界面整体缩放（50~200%），不动系统
  

## 🖥️ 自适应动态适配（不易失效）
- **自动扫描红果内部结构**并缓存，**宿主升级自动重扫**
- 混淆类（单字母，如 `ba5/e65/gc6/c0/f$e/$h`…）走**结构特征匹配 / 按类名后缀****动态定位**
- 扫描失败自动**兜底到已知名**；绝大多数功能还有**运行时兜底**
- 倍速控制器走 **运行时拿实例再 `getClass()`**，天然抗混淆漂移

## 🖥️ 设置入口（两处同步）
- **红果内**：「我的 → 设置 → 白果助手」
- **桌面**：桌面图标 / LSPosed 模块入口
- **配置路径**（`/sdcard/Android/media/com.phoenix.read/hgdj_mod.conf`）

- 包名：`com.hgdj.mod`
- 框架：libxposed（minApiVersion 100 / targetApiVersion 102）
